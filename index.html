    KARTOZA · QGIS NEWS GATHERER

    A month of QGIS, gathered while you sleep¶

    Every release, pull request, blog post, forum thread, user group and video — collected from the whole project and handed to you as show notes.

    Get Started Monthly Reports GitHub

    What it is¶

    QGIS News Gatherer is a Python command line tool that assembles the content for the QGIS monthly news segment. It queries every corner of the project — GitHub, the blog, Planet QGIS, the mailing lists, Discourse, the plugin repository, analytics, Transifex, the user group registry, Mastodon and YouTube — filters everything to one calendar month, and renders the result as presenter-ready show notes.

    Run it for the current month with no arguments. Point it at any past month with --month. Take the PDF into the studio, paste the description straight into YouTube.

    Get the latest report¶

    The last Thursday of every month, a GitHub Action runs the gatherer and publishes the PDF here — no local install required.

    What's in the box¶

    • Every QGIS source, one report

      Releases and merged PRs from GitHub, QEPs, website changes, blog and Planet posts, mailing lists, Discourse threads, PSC minutes, translation progress and sustaining members.

      The section catalogue

    • Videos and Shorts

      QGIS videos and Shorts published in the month, ranked by views, tutorials tagged, with a month-on-month infographic of how the community's output is trending.

      YouTube sections

    • Charts, not just lists

      Usage analytics, plugin downloads, user groups per year and sustaining member levels are rendered as inline SVG charts straight into the PDF.

      Output formats

    • Show notes and chapters

      A YouTube description with estimated chapter timestamps and every link, grouped by section, ready to paste.

      Your first report

    • Runs itself monthly

      A scheduled Action fires on the last Thursday of each month, renders the PDF and publishes it to this site's archive.

      Monthly automation

    • Reproducible Nix dev shell

      One flake provisions Python, WeasyPrint and the Noto font set CI uses, so the PDF you build locally is the PDF the robot builds.
